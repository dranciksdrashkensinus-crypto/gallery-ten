# ТЕНЬ. — анонимная галерея

Тёмная Pinterest-подобная галерея без регистрации и без авторов.

## Что есть

- Две кнопки слева: **главная** (лента) и **+** (загрузка). Больше ничего.
- Загрузка без аккаунта и без имени: сервер не запрашивает и не хранит, кто загрузил фото.
- Общая для всех посетителей лента, бесконечная прокрутка, без лимита на количество фото.
- Поддерживаются JPG, PNG, WebP, GIF, AVIF. Можно загружать много файлов за раз.
- Просмотр нажатием на кадр: стрелки и Esc.

## Запуск

Нужен только Node.js (без `npm install`).

```powershell
cd gallery
npm start
```

Открой <http://localhost:3000>. Порт можно изменить: `$env:PORT=4000; npm start`.

## Хранение

Файлы лежат в `gallery/data/photos/`, список — в `gallery/data/photos.json`.
У каждой записи только технические поля: `id`, расширение, размер, размеры, время.
Полей с автором нет. Удалишь папку `data` — галерея начнётся пустой.
Папка `data/` добавлена в `.gitignore`, поэтому загруженные фото в Git не попадут.

## Публикация как сайт (Render)

GitHub Pages не подойдёт: там только статические файлы и сервер не запустится.
Здесь всё уже настроено через `render.yaml`.

1. Залей содержимое папки `gallery` в GitHub-репозиторий **корнем репозитория**
   (не папкой внутрь). Лишних и временных файлов там нет.
2. Зайди на <https://render.com>, нажми **New + → Blueprint** и выбери этот репозиторий.
3. Render сам прочитает `render.yaml`, создаст Node.js-сервис и подключит диск
   к `/opt/render/project/src/data`. Ничего добавлять вручную не нужно.
4. Через несколько минут открой ссылку вида `https://ten-gallery.onrender.com` — это и есть сайт.
5. Дальше каждый `git push` в репозиторий автоматически обновляет сайт.

Диск нужен, чтобы загруженные фото сохранялись после перезапуска сервера.
Тариф платный (примерно от $7/мес за сервер + 1 ГБ диска). Если надо просто
проверить бесплатно — убери из `render.yaml` блок `disk:` и поставь `plan: free`,
но тогда при перезапуске галерея станет пустой.
