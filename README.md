# ТЕНЬ. — анонимная галерея

Тёмная Pinterest-подобная галерея без регистрации и без авторов.

## Что есть

- Две кнопки слева: **главная** (лента) и **+** (загрузка). Больше ничего.
- Загрузка без аккаунта и без имени: сервер не запрашивает и не хранит, кто загрузил фото.
- Общая для всех посетителей лента, бесконечная прокрутка, без лимита на количество фото.
- Поддерживаются JPG, PNG, WebP, GIF, AVIF. Можно загружать много файлов за раз.
- Просмотр нажатием на кадр: стрелки и Esc.

## Запуск

Нужни только Node.js (без `npm install`).

```powershell
cd gallery
npm start
```

Открой <http://localhost:3000>. Порт можно изменить: `$env:PORT=4000; npm start`.

## Хранение

Файлы лежат в `gallery/data/photos/`, список — в `gallery/data/photos.json`.
У каждой записи только технические поля: `id`, расширение, размер, размеры, время.
Полей с автором нет. Удалишь папку `data` — галерея начнётся пустой.
Папка `data/` добавлена в `.gitignore`, поэтому загруженные фото в Git не попадут.

## Про GitHub

Репозиторий можно просто залить как есть — лишних и временных файлов нет.
Но учти: на **GitHub Pages** только статические файлы, там сервер не запустится
и загрузка фотографий не будет работать. Для рабочей галереи нужен хостинг с Node.js
(Render, Railway, VPS и т. п.).
